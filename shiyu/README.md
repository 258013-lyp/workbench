# 拾愈 · 随手一拍，治愈一整天

> 打开相机随手一拍 → 保留真实照片 + 叠一个手绘情绪注脚 → 给一句刚好够用的文案 → 存进「今日治愈档案」

一个**离线可用、数据不出设备**的移动端 Web App（PWA）。可安装到手机桌面，像原生 App 一样打开即用。

---

## 一分钟跑起来

```bash
cd 拾愈
python -m http.server 8899
```

浏览器打开 `http://localhost:8899`。

**手机使用**：相机需要安全上下文（HTTPS 或 localhost）。两种方式：

| 方式 | 做法 | 说明 |
|---|---|---|
| 局域网（最快） | 手机连同一 WiFi，访问 `http://192.168.0.175:8899` | 部分浏览器会禁用非 HTTPS 相机，此时改用「相册」按钮选图，其余功能完全可用 |
| 部署上线（推荐） | 用 WorkBuddy 的「发布为应用」能力托管 | 拿到 HTTPS 链接，相机、Service Worker、安装到桌面全部可用 |

安装到桌面：手机浏览器打开 → 分享菜单 → 「添加到主屏幕」。

## 产品设计（为什么它和别的贴纸 App 不一样）

| 维度 | 常见做法 | 拾愈的做法 |
|---|---|---|
| 照片处理 | 把人/物变成卡通贴纸 | **保留真实照片**，只叠一个小小的手绘注脚 |
| 生成逻辑 | 选风格 → 出图（style-first） | **先读画面情绪，再给一句话**（emotion-first） |
| 时间单位 | 单张照片 | **一天**：零散瞬间累积成「今日治愈档案」 |
| 核心价值 | 一次性惊喜 | 复利存档：日 → 周 → 月形成「治愈地图」 |
| 数据 | 上传云端 | **IndexedDB 本地存储**，照片和心事不出设备 |
| 成本 | 按次卖 credits | 本地推理，边际成本≈0 → **核心功能永久免费** |

### 差异化四支柱

1. **真实 > 卡通**：可爱贴纸降级为「糖衣」，「被理解」才是药。
2. **反向生成**：主动读出你拍的是「加班后的空桌面」还是「路边睡着的猫」，而不是等你选模板。
3. **一日弧线**：每天自动生成一句话小结，日→周→月累积成情绪地图，这是留存引擎。
4. **本地优先**：隐私是信任卖点，成本是护城河。

## 核心机制

### 情绪引擎（纯离线，无网络）
不调用任何大模型，靠**像素级图像分析**在 30ms 内判定 8 种情绪：

| 特征 | 用途 |
|---|---|
| `L` 平均亮度 | 暗→疲惫/孤独，亮→愉悦 |
| `S` 饱和度 | 高→愉悦，低→平静 |
| `W` 冷暖 (R−B) | 暖→温暖，冷→疲惫 |
| `contrast` 全局对比 | 配合饱和度→焦虑 |
| `edgeDensity` **边缘密度** | 杂乱密集→焦虑（比全局标准差敏感 5 倍） |
| `faceRatio` **上部中央肤色聚集** | 判定画面里有人（避免木色/沙色误报） |
| `skyRatio` / `greenRatio` | 天空、绿植线索 |

判定结果再与**画面线索**（天空/光/夜/绿/人/窗）组合，产出三段内容：
- **情绪标签 + 强度**（百分比）
- **主文案**：8 种情绪 × 10 句 = 80 条，零"治愈/岁月静好/加油/晚安"类空词
- **详情句**：「我看见了……」+ 情绪注解。**与主文案强制使用不同线索**，杜绝语义撞车

### 手绘注脚库
18 个纯手绘 SVG（太阳/星/弯月/云/小雨/水滴/台灯/叶/芽/鸟/毛线团/水面/风/杯/猫爪/爱心/窗/闪），双层描边（白色底衬 + 主色线），保证在深浅照片上都清晰。风格可切换 **手绘 / 印章**。

### 可选：接入视觉大模型
设置页填入接口后，由视觉模型读图并输出结构化 JSON（情绪/文案/详情/注脚），**覆盖**离线结果。不填也能完整使用。Key 只存在本机 localStorage。

## 功能清单

- **拍**：相机取景 / 相册导入 / 前后镜头切换
- **结果卡**：真实照片 + 可拖动的手绘注脚 + 文案 + 详情；一键换文案、换注脚、重拍
- **存档**：存入今日档案；IndexedDB 本地持久化
- **今日**：时间线 + 当日弧线小结（自动统计主导情绪与时段）
- **治愈地图**：月历热力图 + 情绪图例 + 月度统计 + 当月瞬间列表
- **导出**：1080×1350 海报（照片+注脚+文案）/ 全量 JSON 备份
- **设置**：样式切换、模型接入、每晚提醒、导出与清除

## 已知边界

- 离线情绪判定基于色调/构图统计，**不识别具体物件**（不知道那是猫还是杯子）。需要物件级理解请接入视觉模型。
- 「人」线索依赖上部中央肤色聚集，逆光、背影、深肤色可能漏判。
- 相机在非 HTTPS 局域网下可能被浏览器禁用，此时用相册导入。
- 每日提醒依赖页面处于打开状态（纯前端无推送服务）。
